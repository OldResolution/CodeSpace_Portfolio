# CodeSpace_Portfolio
Using CodeSpaces to create a Portfolio

## Description
A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. This portfolio showcases your skills, projects, and provides a way for visitors to contact you.

## Features
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Smooth Navigation**: Smooth scrolling between sections with active link highlighting
- **Mobile Menu**: Hamburger menu for mobile devices
- **Interactive Elements**: Hover effects, animations, and scroll-based animations
- **Contact Form**: Functional contact form with validation and notifications
- **Modern UI**: Clean and professional design with gradient backgrounds

## Sections
1. **Home/Hero**: Eye-catching introduction with call-to-action buttons
2. **About**: Personal introduction and background
3. **Skills**: Display of technical skills and expertise
4. **Projects**: Showcase of your best work with descriptions and links
5. **Contact**: Contact form and social media links

## Technologies Used
- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (ES6+)
- No external dependencies or frameworks

## Getting Started
1. Clone this repository or open it in GitHub CodeSpaces
2. Open `index.html` in your web browser
3. Customize the content with your own information:
   - Update the name and title in the hero section
   - Add your personal information in the About section
   - Update skills to match your expertise
   - Add your actual projects with links and descriptions
   - Add your social media links in the Contact section

## Customization
- **Colors**: Modify CSS variables in `styles.css` under `:root` to change the color scheme
- **Content**: Edit the HTML content in `index.html` to personalize your portfolio
- **Animations**: Adjust animation timing and effects in `script.js`

Simply open `index.html` in any modern web browser. No build process or server required!
